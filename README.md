# 智能日程管理系统PICO_PAL_1.0 - 项目文档

## 项目概述

### 1. 介绍
本项目是一个基于瑞芯微开发板的智能日程管理系统，结合Web编辑界面http://111.230.236.159:3000/, 和嵌入式终端显示，支持手势控制和网络数据同步功能。
### 2. 项目成员
组长：易佳一
组员：袁潇，徐楚淏

## 功能特性

### 1. 核心功能
- 日程信息显示（列表/详情视图）
- 多源数据支持（网络优先，本地备份）
- 精确的日程提醒功能
- 30秒自动返回主界面

### 2. 控制方式
- **手势控制**：
  - 上划：选择上一条
  - 下划：选择下一条
  - 顺时针转圈：进入详情
  - 逆时针转圈：返回/退出

- **键盘控制**：
  - 方向键：上下导航
  - 回车：查看详情
  - q键：退出程序
  - r键：手动刷新数据

### 3. 数据同步
- 自动从Web服务获取最新日程
- 网络不可用时使用本地数据1
- 支持手动刷新数据

## 接口说明

### 1. Web API接口
- **获取日程数据**  
  `GET http://111.230.236.159:3000/api/schedules`
  
  响应格式：
  ```json
  {
    "schedule_count": 4,
    "schedules": [
      {
       "id":1,"name":"每周会议",
       "is_repeated":true,
       "repeat_type":"week",
       "which_day":1,"
       start_date":"2023-11-01",
       "end_date":"2025-04-16",
       "exact_date":null,
       "exact_time":"09:11",
       "reminder_count":1,
       "reminder_interval":5
        ...
      }
    ]
  }
  ```

### 2. 手势控制映射

| 手势动作 | 对应按键事件 | 功能说明 |
|----------|--------------|----------|
| 上划 | KEY_UP | 选择上一条 |
| 下划 | KEY_DOWN | 选择下一条 |
| 顺时针转圈 | KEY_ENTER | 进入详情 |
| 逆时针转圈 | KEY_ESC | 返回/退出 |

## 开发调试

### 常见问题排查

1. **手势识别不灵敏**：
   ```bash
   # 检查传感器连接
   i2cdetect -y 1
   ```

2. **网络连接失败**：
   ```bash
   curl -v http://111.230.236.159:3000/api/schedules
   ```

3. **显示异常**：
   ```bash
   export DISPLAY=:0
   xrandr --output HDMI-1 --mode 800x480
   ```
